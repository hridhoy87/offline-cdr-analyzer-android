MainActivity.java Java Activity

Application entry point and intelligence dashboard. Manages file picker, Python engine execution, temporal heatmaps, silent background movement correlation, peek preview, and global search.

Lines: 1,464 SDK 35 • Immersive UI

Lines: 248 Portrait Locked

Lines: 585 Sensor Orientation

Dense landscape correlation table rendering exact sector and address matches. Offers instant in-memory datetime refinement without re-reading source files. Exports to PDF and Excel.

Lines: 599 Landscape Locked

🛡️ Core Engineering Invariants

  • Disk-Backed Cache Rule: Never store heavy DataFrames or JSON payloads in Java static fields or Intent bundles. Always write to Documents/CDR_Reports/.cache_engine/ and pass file paths across Activities to prevent Android TransactionTooLargeException.
  • Phone Number Sanitization Invariant: Phone numbers must always undergo str.replace(r'^\+?88|\D', '', regex=True).str[-11:] to normalize variants (+88017..., 88017..., 017...) into exact 11-digit keys.
  • Async Chaquopy Rule: All calls to pyModule.callAttr(...) must execute inside a background worker thread (new Thread(...)) to keep the Android Main Looper 60fps responsive.
  • FileProvider Sharing Rule: All files opened in external viewers (Excel, PDF) must be resolved through FileProvider.getUriForFile() with FLAG_GRANT_READ_URI_PERMISSION.
  • Inactivity Timeout Rule: Sessions expire after 30 minutes of idle time (INACTIVITY_TIMEOUT = 30 * 60 * 1000) to maintain security hygiene and purge transient memory.
